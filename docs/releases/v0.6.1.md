# HermesKey v0.6.1

This maintenance release protects dictated text and makes default diagnostics safer to share after review. It does not change how the hotkey starts and stops dictation.

## Privacy and input fixes

- Direct typing now feeds dictated text to `ydotool`, `wtype` and `xdotool` through standard input instead of process arguments. The active window's caption is no longer passed to a matching helper as a process argument, and custom model names/paths are no longer arguments of the long-running speech server.
- On older `ydotool` builds without safe stdin support, HermesKey **will not type text insecurely**. If clipboard backup is enabled, the text remains available for manual paste; with backup disabled, nothing is inserted or copied. The existing non-ASCII clipboard-paste behavior still requires clipboard backup.
- Doctor shows actionable health checks without embedding raw service journal lines, device lists or personal config/model paths. Speech-server Python logging keeps HermesKey's own sanitized status messages but suppresses third-party model/network INFO output. Previous journal entries are not erased; review any logs before sharing them.

## Upgrading

Once this release is published, run the standard installer from your graphical desktop session, without `sudo`:

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash
```

The installer preserves `~/.config/hermeskey/hermeskey.env` and restarts the user services. Check `hermeskey --version` (expect `0.6.1`), run `hermeskey-doctor`, then test a harmless phrase in a focused editor. `./install.sh` from a checkout is sufficient on machines with an existing working speech Python venv but does not create one.

**Local-first does not mean network-free at startup:** the model library may still request model metadata when starting the service, even if its files are cached. Hiding third-party INFO output does not prevent that request; a strict-offline mode is tracked in [#65](https://github.com/graygarbage/HermesKey/issues/65). Clipboard backup, when enabled, may also leave dictated text in desktop clipboard history; see [configuration](https://github.com/graygarbage/HermesKey/blob/v0.6.1/docs/CONFIGURATION.md). Other security hardening remains in progress; this release does not claim to resolve every advisory.

A repository social-preview image was also added to `assets/` for an optional manual upload to GitHub; it is not part of the installed app experience.
